# b8k-max — клиент для MAX

Неофициальный клиент для мессенджера MAX: крупно, без браузера (`b8k-max`).

- Протокол веб-версии MAX через [PyMax](https://pypi.org/project/maxapi-python/)
  (MIT): WebSocket, как у web.max.ru, без веб-движка — около 55 МБ вместо
  второго браузера. Случайная телеметрия PyMax выключена.
- Своя телеметрия, как у приложения MAX, чтобы сервер реже отличал программу
  от него: только настоящие переходы между экранами (список, чат, окно
  спрятано) и время открытия чата, без текстов и имён. Включена; выключается
  в настройках (шестерёнка в заголовке) и хранится в
  `~/.config/b8k/max.conf` (`[max]`, `telemetry = no`).
- Первый запуск показывает QR-код для входа с телефона; сессия хранится в
  `~/.local/share/b8k-max/web.db` (права 600).
- Список чатов и чат: пузыри, фотографии, крупное поле ввода. Новые
  сообщения приходят сразу и вибрируют; вибрацию можно выключить в
  настройках (`buzz = no` в `~/.config/b8k/max.conf`). Касания
  кнопок вибрируют по-прежнему.
- Поиск (лупа над списком): по номеру телефона — человек в MAX, ему можно
  написать или добавить его в контакты; по ссылке `max.ru/…` или `@имя` —
  канал или группа, на них можно подписаться; по названию — свои чаты.
  Корзина в заголовке чата удаляет переписку у себя (у собеседника она
  остаётся), выводит из группы или отписывает от канала — после вопроса.
  Всё по одному и руками: массового поиска и добавления нет.
- Сообщения только от контактов (по умолчанию): переписки с теми, кого нет
  в ваших контактах, не видны, не вибрируют и не считаются на кнопке
  панели. Своими считаются и те, кому вы написали сами, а при первом
  запуске этой версии — все, с кем уже есть переписка. Сообщения остаются в
  MAX; выключается в настройках (`contacts_only = no`). В самом MAX такой
  настройки нет, фильтр работает только в этой программе: на телефоне
  сообщения от незнакомых видны как обычно.
- Приглашать в чаты могут только контакты (по умолчанию): это настройка
  самого MAX, она действует и на телефоне. Программа ставит её один раз для
  аккаунта и потом только когда её переключают здесь (`invites = no` в
  `~/.config/b8k/max.conf`), так что поменять её на телефоне можно.
- Живёт в фоне (`--background`): закрытие окна его только прячет, кнопка
  панели возвращает тот же процесс. Число непрочитанных диалогов и групп
  (без каналов) — на кнопке панели.
- Фотографии загружаются только по https с `oneme.ru` и `max.ru`: адреса
  приходят внутри сообщений.
- Последние сообщения чатов кэшируются в `~/.cache/b8k-max/` (права 600).

## Это неофициальный клиент

Программа не связана с VK, ООО «Коммуникационная платформа» и командой MAX,
ими не проверена и не одобрена. «MAX» и «Макс» — обозначения их владельца;
здесь название служит только тому, чтобы сказать, с каким сервисом работает
программа. Значок программы свой, не логотип MAX.

Пользовательское соглашение MAX (<https://legal.max.ru/ps>, пп. 4.3.7 и
4.3.10) запрещает пользоваться сервисом иначе, чем через интерфейс компании,
и компания вправе ограничить доступ за нарушение (п. 9.2). С осени 2025 года
MAX блокирует доступ через сторонние клиенты. Вход через эту программу может
закончиться блокировкой аккаунта; пользуйтесь ей на свой риск и только для
своего аккаунта. Программа не делает рассылок и не собирает чужих данных.

## Установка

Нужны Python 3, GTK 3, PyGObject, `wget` и `unzip` (есть в BusyBox). PyMax
`install.sh` скачивает сам: закреплённый wheel 2.4.1 с проверкой sha256 —
в `/usr/local/lib/b8k-max`, кэш загрузки — в `$B8K_CACHE` (по умолчанию
`.cache/` здесь). В Alpine:

```
apk add python3 py3-gobject3 gtk+3.0
```

Поставить в систему (нужен root):

```
sh install.sh            # в /
sh install.sh /mnt/root  # в другой корень, например при сборке образа
```

`install.sh` кладёт программу в `/usr/local/bin/b8k-max`, значок и раздел для
панели оболочки в `/usr/local/share/b8k/apps.d/max.conf`.

## Оболочка планшета

Программа сделана для оболочки
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)
(Linux на Lenovo YOGA Tablet 10 B8000-H), её сборка ставит программу
отсюда по тегу. Если в системе есть модуль оболочки
`/usr/local/share/b8k/python/b8k_ui.py`, программа берёт из него вибрацию, общий вид заголовка и
число на кнопке панели.
Без него она работает на любом рабочем столе с GTK 3.
