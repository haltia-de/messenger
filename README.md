# MAX

Мессенджер MAX крупно, без браузера (`b8k-max`).

- Протокол веб-версии MAX через [PyMax](https://pypi.org/project/maxapi-python/)
  (MIT): WebSocket, как у web.max.ru, без веб-движка — около 55 МБ вместо
  второго браузера. Телеметрия PyMax выключена.
- Первый запуск показывает QR-код для входа с телефона; сессия хранится в
  `~/.local/share/b8k-max/web.db` (права 600).
- Список чатов и чат: пузыри, фотографии, крупное поле ввода. Новые
  сообщения приходят сразу и вибрируют.
- Живёт в фоне (`--background`): закрытие окна его только прячет, кнопка
  панели возвращает тот же процесс. Число непрочитанных диалогов и групп
  (без каналов) — на кнопке панели.
- Фотографии загружаются только по https с `oneme.ru` и `max.ru`: адреса
  приходят внутри сообщений.
- Последние сообщения чатов кэшируются в `~/.cache/b8k-max/` (права 600).

Репозиторий пока закрытый.

## Установка

Нужны Python 3, GTK 3, PyGObject, `wget` и `unzip` (есть в BusyBox). PyMax
`install.sh` скачивает сам: закреплённый wheel 2.4.1 с проверкой sha256 —
в `/usr/local/lib/b8k-max`, кэш загрузки — в `$B8K_CACHE` (по умолчанию
`.cache/` здесь). В Alpine:

```
apk add python3 py3-gobject3 gtk+3.0
```

Поставить в систему (нужен root):

```
sh install.sh            # в /
sh install.sh /mnt/root  # в другой корень, например при сборке образа
```

`install.sh` кладёт программу в `/usr/local/bin/b8k-max`, значок и раздел для
панели оболочки в `/usr/local/share/b8k/apps.d/max.conf`.

## Оболочка планшета

Программа сделана для оболочки
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)
(Linux на Lenovo YOGA Tablet 10 B8000-H), её сборка ставит программу
отсюда по тегу. Если в системе есть модуль оболочки
`/usr/local/share/b8k/python/b8k_ui.py`, программа берёт из него вибрацию, общий вид заголовка и
число на кнопке панели.
Без него она работает на любом рабочем столе с GTK 3.
